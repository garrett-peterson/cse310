# Development Environment

{Describe the tools that you used to develop the software}
I used visual studio code and chat GPT

{Describe the programming language that you used and any libraries.}
I used C++. The program uses several libraries from the C++ Standard Library, including iostream for input and output, string for working with text, list and vector for storing data, algorithm for searching lists, and fstream for reading and writing files. I also used cctype to check and convert characters and cstdlib and ctime to randomly select a word for the game.
